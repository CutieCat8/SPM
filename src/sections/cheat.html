คู่คำที่ชอบสลับกันในตัวเลือก

คู่วิธีแยก
Need ↔ RequirementNeed = เป้าหมาย/ความรู้สึกที่อยากเติมเต็ม · Requirement = สิ่งที่ต้องทำให้สำเร็จเพื่อบรรลุ Need
Top-down ↔ Bottom-up (แหล่งเกิดโครงการ)Top-down = เจตนารมณ์ผู้บริหาร · Bottom-up = ปัญหาในสายงานปกติ
Top-down ↔ Bottom-up (สร้าง WBS)Top-down = PM มีประสบการณ์เทคนิคสูง มองภาพรวมออก · Bottom-up = ทีมมีบทบาทมาก เสียเวลามาก แต่เหมาะกับของใหม่
Program ↔ ProjectProgram = ชุดของโครงการ (≥2) ที่มีเป้าหมายเดียวกัน · Project = กลุ่มของกิจกรรมที่สัมพันธ์กัน
include ↔ extendinclude = mandatory (ต้องมี) · extend = optional (ไม่มีก็สมบูรณ์)
Do while ↔ Do untilDo while ตรวจก่อนทำ ออกเมื่อเท็จ · Do until ทำก่อนตรวจ ออกเมื่อจริง
As-is ↔ To-beAs-is = ระบบงานปัจจุบัน · To-be = ระบบงานใหม่จาก Requirements ล่าสุด
Macro ↔ Micro ProjectMacro = ระดับชาติ ข้ามภูมิภาค วิสัยทัศน์ระยะยาว · Micro = ระดับองค์กร/โครงการรายตัว มี task list ละเอียด
Fork ↔ JoinFork = แยกเป็นคู่ขนาน · Join = รวมหลายงานเข้าเป็นงานเดียว
Agile ↔ Scrum ↔ KanbanAgile = แนวคิด/Iterative · Scrum = framework แบบ Incremental มี sprint และ 3 บทบาท · Kanban = กระดานแสดง workflow ตาม Status
Estimate ↔ Budget ↔ BaselineEstimate = คาดว่าจะใช้ · Budget = เงินที่จัดสรร · Baseline = แผนที่อนุมัติสำหรับเทียบผล
PV ↔ EV ↔ ACPV = ควรเสร็จตามแผน · EV = เสร็จจริงคิดตามงบ · AC = จ่ายจริง
Variance ↔ IndexSV/CV ใช้ลบและมีหน่วยเงิน · SPI/CPI ใช้หาร ไม่มีหน่วย; EV อยู่หน้าเสมอ
QA ↔ QCQA = ป้องกัน/กระบวนการ · QC = ตรวจจับ/ผลิตภัณฑ์
Burndown ↔ BurnupBurndown = งานที่เหลือ · Burnup = งานเสร็จสะสมเทียบ Scope รวม จึงเห็น Scope Creep
Aggregation ↔ CompositionAggregation = Part อยู่ได้เอง · Composition = วงจรชีวิต Part ผูกกับ Whole
Mitigation ↔ ContingencyMitigation = ลดก่อนเกิด · Contingency = แผนใช้เมื่อ Risk เกิด/Trigger ทำงาน
Risk ↔ IssueRisk = ยังไม่แน่ว่าจะเกิด · Issue = เกิดแล้วและต้องแก้
Change Management ↔ ControlManagement = คนและการยอมรับ · Control = คำขอ กระบวนการ และ Baseline
Completion ↔ ClosureCompletion = งานเสร็จ · Closure = ยอมรับ ส่งต่อ ปิดภาระ และเก็บบทเรียนครบ
Warranty ↔ MaintenanceWarranty แก้ defect ตามสัญญาหลัง Sign-off · Maintenance คือบริการต่อเนื่องหลัง Warranty ซึ่งมักมีสัญญา/ค่าใช้จ่ายแยก
